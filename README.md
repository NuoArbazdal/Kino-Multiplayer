# Kino Multiplayer

Browser-only cooperative multiplayer adaptation project for Kino der Toten.

## Source

The original browser game is maintained at https://github.com/luckeyfaraday/kino-der-toten. Its code and asset licensing must be reviewed before reuse or redistribution.

## Architecture

- Browser game client (to be integrated from the source project)
- Hosted WebSocket game server for room creation, player state and zombie synchronization
- Up to four players per private room

This repository is initialized; multiplayer gameplay has **not yet been implemented or deployed**.
